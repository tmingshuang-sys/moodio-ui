# Moodio 本地助手

让 Moodio 里的成片**一键进达芬奇**：点一下，达芬奇自动打开，时间线上的片段已经按顺序排好。

网页自己做不到这两件事，所以需要这个小程序代劳：

- 达芬奇没有注册 URL scheme，网页启动不了它（剪映能被唤起是因为它注册了 `videocut://`）
- 浏览器拿不到本机绝对路径，而 FCPXML 的媒体引用必须是绝对路径

## 怎么用

只用 Python 标准库，macOS 自带的 python3 就能跑，不用装任何依赖：

```bash
python3 moodio-helper.py
```

看到「已启动」就行，把这个终端窗口留着。回到 Moodio，点视频右上角的导出图标，达芬奇就会自己打开。

想换端口或存放位置：

```bash
python3 moodio-helper.py --port 17817 --dir ~/Movies/Moodio
```

片段默认存在 `~/Movies/Moodio/<创作名>/`，同一条成片导第二次会自动叫「… 2」，不会覆盖。

## 它做了什么

1. 在 `127.0.0.1:17817` 上等 Moodio 传片段过来，写到存放目录
2. 生成 FCPXML（时间线按片段顺序首尾相接）
3. 通过达芬奇自带的脚本接口导入时间线，切到剪辑页；达芬奇没开就先把它启动起来

## 安全

- 只监听 `127.0.0.1`，同一台电脑之外访问不到
- 只接受来自 Moodio 站点与本地开发地址的请求，别的来源直接拒绝
- 文件名会过滤路径分隔符，只会写进存放目录里面

## 没装助手也能用

Moodio 探测不到助手时会退回到导出片段文件夹：片段按 `clip_01`、`clip_02` 顺序命名，附一份 FCPXML 和 EDL，你在达芬奇里「文件 › 导入 › 时间线」选那个 FCPXML 即可。

## 要求

- macOS
- DaVinci Resolve（免费版即可，实测 19.0.0）
- Python 3（系统自带的 `/usr/bin/python3` 就行）
